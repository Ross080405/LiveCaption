# LiveCaption 实时字幕（macOS）

把麦克风或电脑播放的声音实时转成字幕，显示在一个始终置顶的悬浮字幕条上。
两种识别引擎可选，都**在本机识别、不上传音频**：
- **系统识别**：macOS 自带，快、省电
- **Whisper 高精度**：开源 Whisper 模型（通过 WhisperKit 在 Apple 芯片上运行），对**印度口音等各种口音、中英混说**明显更准

## 功能
- 🎙 **两种音频来源**：麦克风 / 系统声音（看视频、开会、直播时直接出字幕）
- 💬 **悬浮字幕条**：置顶、可盖在全屏视频上；拖动移动，拖边缘调整大小；可「锁定」让鼠标穿透
- 🌏 **多语言**：普通话、台湾中文、粤语、英语、日语、韩语、法语、德语、西班牙语
- ✂️ **自动断句**：停顿约 1.2 秒自动换行，并在后台用最终结果修正上一句
- 💾 **导出**：复制全部文字、保存 `.txt`（带时间）、导出 `.srt` 字幕文件
- 字号 / 背景深浅可调，设置自动保存
- 🤖 **交给桌面 AI**：字幕实时存成文件，按 **⌥⌘A** 一键发给你在用的 Grok / Claude / ChatGPT 等桌面应用，**不需要 API Key**

## 系统要求
- macOS 14 Sonoma 或更新
- **Xcode 16 或更新**（App Store 免费下载，用于编译）
- 使用 Whisper：建议 Apple 芯片（M1 及以后）；Intel Mac 能运行但会很慢
- 第一次编译需要联网（下载 WhisperKit 源码）；第一次用 Whisper 需要联网下载模型

## 编译和运行
```bash
cd LiveCaption
./build.sh
open build/LiveCaption.app
```
`./build.sh --install` 会把应用装到「应用程序」文件夹；装过之后，每次 `./build.sh` 都会顺手更新那一份。

**让系统权限在重新编译后保留（推荐，只需一次）：**
```bash
./scripts/make-signing-cert.sh
```
macOS 是按签名来认应用的。默认的临时签名（ad-hoc）每次编译都不一样，所以每次重新编译后，麦克风 / 语音识别 / 屏幕与系统录音都要重新授权。这个脚本在登录钥匙串里建一个本机自签名证书，`build.sh` 发现它就会用它签名，权限从此跨编译保留。之后第一次编译时系统可能提示「codesign 想要使用密钥」，输入登录密码并点「始终允许」。

打开应用会出现主窗口（关掉后点菜单栏图标 →「打开 LiveCaption 窗口」，或再次双击应用）。同一个界面也可以在浏览器里访问 <http://localhost:17890>：

- **一屏只做一件事**：没在记录时只有一个「开始」按钮；记录时是正在出现的字幕，标题、计时、暂停 / 结束在顶部。
- **命名两种方式**（设置 → 保存与命名，或开始按钮下面的链接切换）：
  - **自动命名**：按命名规则起名，默认 `字幕_{date}_{time}`，可用 `{date}` `{time}` `{year}` `{month}` `{day}` `{hour}` `{minute}` `{weekday}` `{source}` `{language}`
  - **开始前先起名**：先输入名字再开始（留空就按规则）；用菜单 / ⌥⌘P 开始时会弹一个小输入框
  - 不管哪种，记录中或结束后点标题都可以随时改名
- **记录库**：之前的记录收在左侧，默认收起（左上角按钮或按 `/` 打开），可搜索。点开一份是全幅阅读视图，**渲染 Markdown**（标题、列表、表格、代码、待办），可切换衬线 / 无衬线字体、显示 / 隐藏时间戳，可接着写入、改名、移到废纸篓，也可以点「编辑」直接改文字（⌘S 保存；正在记录的那份要结束后才能改）。
- **预览任意 Markdown**：把 `.md` / `.txt` 文件拖进页面即可。
- **设置**在右上角的抽屉里：识别模型、字幕条外观等。

> ⚠️ 请用 `open` 或双击启动，不要在终端里直接运行里面的二进制文件，否则权限会被记到「终端」名下。

## 打包给别人用
```bash
./scripts/make-dmg.sh
```
生成 `build/LiveCaption-版本号.dmg`，不会动「应用程序」里你自己在用的那一份。对方不需要 Xcode，拖进「应用程序」即可；第一次打开时窗口里有引导，带着允许权限、选识别引擎。

- **没有 Apple 开发者账号**（默认）：临时签名。对方第一次打开会被系统拦下，需要按安装包里的「首次打开说明.txt」到「系统设置 → 隐私与安全性」点一次「仍要打开」。
- **有开发者账号**：正式签名加公证，对方双击就能打开（这条路径还没有实际跑过）：
  ```bash
  xcrun notarytool store-credentials livecaption     # 只需一次，按提示输入 Apple ID、团队 ID、App 专用密码
  SIGN_IDENTITY="Developer ID Application: 你的名字 (TEAMID)" NOTARY_PROFILE=livecaption ./scripts/make-dmg.sh
  ```

## 使用
1. 启动后菜单栏会出现一个 💬 字幕图标，屏幕下方出现字幕条。
2. 点菜单栏图标（或在字幕条上**右键**）→ **开始字幕**。
3. 第一次会弹出权限请求：
   - **语音识别**、**麦克风**：点「允许」
   - 选「系统声音」时需要 **屏幕与系统录音** 权限：在系统设置里打开后，**退出并重新打开**本应用
4. 看视频时可以选「锁定字幕条」，这样字幕条不会挡住鼠标点击（解锁请用菜单栏图标）。

## Whisper 高精度识别
菜单「识别引擎」→ 选 **Whisper 高精度**，然后像平常一样开始记录。

- **第一次使用**会自动下载模型（字幕条上显示进度），下载完还要加载一次，第一次加载可能要几分钟（系统在为你的芯片优化模型），之后就快了。
- 建议开会前点「识别引擎 → 提前下载并加载 Whisper 模型」，开始记录时就不用等。
- **模型选择**：
  | 模型 | 说明 |
  |---|---|
  | Large v3 Turbo（默认） | 最准，速度也快，占用空间较大 |
  | Large v3 Turbo 压缩版 | 626MB，准确度接近，省空间 |
  | Small | 更小更快，老电脑用；准确度较低 |
- **语言**：默认按「识别语言」固定（印度口音英语选 English (India) 或任一英语都行，Whisper 内部都是英语模型）。如果一场会里**中英文混着说**，打开「Whisper 自动检测语言」。
- 选「中文（普通话）」时，结果会自动转成简体。
- 和系统识别的区别：Whisper 是一句一句识别的，字幕大约**晚 1 秒**出现，说话停顿后整句会再校正一次。
- 模型保存在 `~/Library/Application Support/LiveCaption/whisper`，不用了可以删掉这个文件夹释放空间。

## 录音：开始 / 暂停 / 结束
菜单栏图标（或在字幕条上右键）：

| 状态 | 菜单里能做的 |
|---|---|
| 没有记录 | **● 开始新记录**：新建 `文稿/LiveCaption/字幕_日期_时间.md`<br>**○ 接着写入已有文件**：从最近的记录里选一个，或「选择其他文件…」，新字幕追加在原内容后面 |
| 录音中 | **⏸ 暂停** / **⏹ 结束本次记录** |
| 已暂停 | **▶︎ 继续**：默认接着写入当前文件，并插入一行「—— 暂停后继续 ——」 / **⏹ 结束本次记录** |

- 全局快捷键 **⌥⌘P**：没有记录时开始新记录，录音中暂停，暂停时继续
- 字幕条和菜单栏图标会显示当前状态（暂停时图标变成 ⏸）
- 「结束」后文件就定稿了；下次开始时再选新建还是接着写哪个文件
- 接着写入已有文件时，原内容不会被改动，只在后面追加
- 一句都没录到就结束，不会生成空文件

## 交给桌面 AI（Grok / Claude / ChatGPT…）
不用 API Key，直接配合你电脑上已经在用的桌面 AI 应用。

**方式一：让 AI 自己读字幕文件**
字幕会一边识别一边写进你当前记录的文件，同时同步一份到固定路径：
```
~/Documents/LiveCaption/最新字幕.md   ← 始终是当前正在记录的内容
```
文件大约每半秒刷新一次。**正在说、还没说完的那一句也会写进去**，行尾带 ` …（识别中）` 标记；这一句说完后，这一行会被定稿的句子替换。所以让 AI 盯着这个文件，就能跟上正在进行的对话，不用等一句说完。

在你的桌面 AI 里直接说：「看一下 文稿/LiveCaption/最新字幕.md，刚才说的截止日期是哪天？」
（菜单里有「复制字幕文件路径」「在访达中显示实时字幕文件」，方便你拖给 AI 或粘贴路径）

**方式二：一键发送（⌥⌘A）**
在任何地方按 **⌥⌘A**：当前记录文件的完整内容会复制到剪贴板，并自动切到你的 AI 应用，按 **⌘V** 粘贴、回车即可。
菜单「交给桌面 AI」里还有「发送字幕并请它总结」「发送字幕并请它提取待办」。

**选择 AI 应用**：菜单「交给桌面 AI」底部会列出这台 Mac 上找到的 Grok、Claude、ChatGPT 等；没列出来的点「选择其他应用…」自己挑。

## 常见问题
| 问题 | 解决 |
|---|---|
| 提示「语音识别暂时不可用」 | 系统设置 → 键盘 → **听写** 打开一次；或检查网络 |
| 没有字出来 | 检查系统设置 → 声音 → 输入 选对了麦克风；确认识别语言选对 |
| 重新编译后权限异常 | 本地签名每次编译都会变，可重置后重新授权：`tccutil reset Microphone local.livecaption.app`（SpeechRecognition / ScreenCapture 同理） |
| 系统声音没反应 | 确认已在「屏幕与系统录音」里允许 LiveCaption，并重启了应用 |
| ⌥⌘A 没反应 | 可能和其他软件的快捷键冲突，用菜单栏图标 →「交给桌面 AI」 |
| 桌面 AI 读不到字幕文件 | 在系统设置 → 隐私与安全性 → 文件与文件夹 中允许该 AI 应用访问「文稿」；或直接把文件拖进 AI 对话框 |
| Whisper 模型下载失败 | 检查网络能否访问 huggingface.co；或先切回「系统识别」 |
| Whisper 字幕出现「谢谢观看」之类没说过的话 | Whisper 在长时间静音时偶尔会「幻听」，已过滤常见情况；环境噪音大时更容易出现 |
| 编译报错找不到 swift / Xcode | 安装 Xcode 16+ 后运行一次 `sudo xcode-select -s /Applications/Xcode.app` |
| Intel Mac | 部分语言不支持本地识别，会自动改用在线识别（需联网） |

## 代码结构
```
Sources/
  AppDelegate.swift         菜单栏图标、菜单、设置、导出
  RecordingFile.swift       记录文件：新建 / 接着写入 / 暂停标记 / 实时保存
  AgentBridge.swift         一键发送给桌面 AI
  HotKey.swift              全局快捷键 ⌥⌘A
  Transcriber.swift         音频采集 + 分段语音识别 + 断句（系统识别 / Whisper 两种引擎）
  WhisperEngine.swift       Whisper 模型下载加载 + 按停顿切句的实时识别
  SystemAudioCapture.swift  用 ScreenCaptureKit 采集系统声音
  SubtitleWindow.swift      置顶悬浮字幕条
  DashboardWindow.swift     应用主窗口（显示控制台页面）
  DashboardServer.swift     只监听本机的 HTTP 服务
  DashboardPage.swift       控制台页面（单文件 HTML）
Package.swift               依赖（WhisperKit 1.1.1）
Info.plist                  权限说明文字等
build.sh                    一键编译成 .app
```
